# Axcenta Website Preview

Temporary customer-review preview for the Axcenta website revamp.

## Scope

- Static HTML, CSS, JavaScript, and local visual assets
- No ERPNext credentials, private customer records, or form-submission endpoints
- Contact form is intentionally non-submitting in this preview
- Existing ERPNext website is not modified by this repository

## Preview pages

- index.html — redesigned homepage
- services.html — services and methodology
- wwa.html — who we are and approach
- story.html — vision, history, and leadership
- contact.html — safe local contact-form preview
- about.html, home.html, mpage.html — legacy-route previews

## Deployment note

This repository is intended for temporary review through GitHub Pages. It should be treated as a staging preview until the customer approves the content, links, images, branding, and final ERPNext implementation.
